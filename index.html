Checklist de segurança

✓ Capnografia + monitor multiparamétrico
✓ Fonte de O₂ e bolsa-válvula-máscara testada
✓ Tubo com cuff (tamanho adequado pelo peso/comprimento)
✓ Laringoscópio (videolaringoscópio preferível)
✓ Aspirador + sonda + fio-guia
✓ Material de fixação e coxim
✓ Acesso venoso periférico + medicações SRI
✓ Maleta de via aérea difícil
✓ Monitor neuromuscular quantitativo (recomendado ESAIC 2026)
✓ Sugammadex disponível se rocurônio utilizado
